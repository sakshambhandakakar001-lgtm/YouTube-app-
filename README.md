# 🎬 YouTube Clone - Video Sharing Platform

A lightweight, fully functional video-sharing web application built using Python Flask, SQLite, and modular blueprints. Designed, coded, and structured with mobile-first execution.

---

## 🚀 Features
* **User Authentication:** Secure user registration and login sessions using Werkzeug security for password hashing.
* **Modular Architecture:** Clean separation of concerns using Flask Blueprints (`youtube_core`, `video_features`).
* **Content Management:** Upload, display, and manage videos seamlessly.
* **Database Integration:** Utilizes SQLite for lightweight data storage.
* **Concurrency Support:** Built-in threading for handling background processes efficiently.

---

## 🛠️ Tech Stack
* **Backend:** Python, Flask
* **Database:** SQLite3
* **Security:** Werkzeug Security
* **Environment:** Termux (Mobile Development Environment), GitHub for Version Control
